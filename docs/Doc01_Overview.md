# Doc01 项目总览 & 立项说明书

> 版本：V2.0（2026-10-21 优化：版本规划纳入无人值守模式 Doc16、设置页规范 Doc17，安全基线补充"可显式开启的受保护自动同意"）

## 1. 项目名称

- 英文：scToLocalDesk
- 中文：SC 邻桌
- 命名空间：`sc::localdesk`

## 2. 项目背景

企业内网场景，向日葵、ToDesk 依赖公网，存在数据出网风险、外网访问限制；现有方案不适合涉密 / 内网隔离企业。自研一套仅在内网运行的远程协助工具，面向无计算机基础企业员工与 IT 运维。

## 3. 项目目标

1. 纯局域网运行，无公网服务器依赖；UDP 组播自动发现设备，**使用设备别名寻址，无需手动输入 IP**
2. 单 EXE 程序，同一个程序支持【被控等待协助】/【主动远程控制别人】两种模式，运行时一键切换
3. 安全基线：所有新连接请求默认必须被控用户手动同意，无静默连接；预留**显式开启、独立密码保护、全程审计**的无人值守模式（V1.1，设计见 [Doc16](./Doc16_Unattended_Mode.md)）
4. 能力：远程屏幕画面、键鼠透传、双向文件传输
5. 架构目标：工业级 C++、面向接口、组件可插拔；核心业务层（core）无 Qt 依赖，Qt 仅作为平台适配层，便于后续迁移其他平台
6. 日志系统基于 spdlog，结构化日志，可追溯会话、异常、传输记录
7. 提供统一设置页（[Doc17](./Doc17_Settings_Page.md)），全部行为可配置、可持久化

## 4. 目标用户

- 被控端：企业普通员工，无计算机基础（小白用户）
- 控制端：企业 IT 运维人员

## 5. 版本规划

| 版本 | 范围 |
| --- | --- |
| V1.0（本期开发） | 基础能力闭环：UDP 别名发现、WebSocket 会话、屏幕流、键鼠、双向文件传输、托盘、QML 界面、spdlog 日志、连接确认机制、设置页基础项 |
| V1.1（迭代） | 多显示器、剪贴板同步、传输二次确认开关、**无人值守模式（独立密码 + 挑战应答鉴权，Doc16）**、设置页安全页签 |
| V1.2（迭代） | 设备白名单、失败次数锁定、隐私黑屏保护、会话录像 |

## 6. 非目标（V1 不做）

公网穿透、P2P 外网、账号登录、云端管理后台、移动端、Linux 客户端。

> 注意：无人值守模式运行在纯内网、密码本机校验，不引入任何云端依赖，不属于上述非目标。

## 7. 软硬件运行基线

- OS：Windows10 1809+ / Windows11
- 编译环境：Qt 6.5.3，MSVC2019 16.11+
- 依赖：spdlog + fmt、FFmpeg（可选编码）
- 网络：同一局域网、支持 UDP 组播；防火墙放行指定端口（见 [Doc15](./Doc15_Deploy_Guide.md)）
