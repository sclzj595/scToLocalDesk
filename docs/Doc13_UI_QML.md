# Doc13_UI_QML.md（SC 邻桌 scToLocalDesk UI 设计规范）

> 项目：scToLocalDesk（SC 邻桌）
> 视觉基准：**iOS16 复古毛玻璃（模糊值固定 18px，非 iOS17 亚克力）+ macOS 现代 BS 菜单栏 + 双主题（浅色 / 深色）+ 粉紫主色调**
> 技术栈：Qt6.5.3 + QML + QtQuick.Controls 2 + BackdropBlur 磨砂材质
> 文档约束：本规范所有颜色、圆角、模糊参数为全局唯一基准，与 Doc17 配置项严格对齐，不得随意修改。
> 双实现对照：本规范同时落地两套 UI —— `src/ui/qml`（QML，主实现）与 `src/ui/qwidget`（QWidget C++ + QSS 对照实现），供效果比对。

## 一、整体设计总则（强制条款）

### 1.1 视觉风格定义

1. 材质：**iOS16 Frosted Glass 毛玻璃（固定 blurRadius=18px）**；仅导航栏、侧边栏、弹窗、Dock 面板使用磨砂玻璃；内容区域禁止叠加玻璃效果，保证内容优先。
2. 分层模型（三层严格划分）
   - 顶层：玻璃导航层（菜单栏、顶部标题栏、左侧 Dock）
   - 中层：业务内容层（设备列表、远程画面、文件传输面板，纯色背景，无模糊）
   - 底层：窗口底色
3. 菜单栏风格：macOS 现代 BS 横向菜单栏，毛玻璃背景、无实色底色、hover 高亮、下拉弹窗同样启用 18px 磨砂玻璃。
4. 主题模式：双主题自动切换（浅色 / 深色），全局色值统一写入 config.ini（Doc17）；支持手动切换开关。
5. 圆角全局统一：大面板 16px；卡片 / 弹窗 12px；按钮 / 输入框 8px；菜单条目 6px；分割线 1px 细线条。

### 1.2 全局固定参数（不可修改）

| 参数项 | 固定值 | 适用范围 |
| --- | --- | --- |
| 背景模糊半径 | **18px（强制固定，严禁改为亚克力动态模糊）** | 所有毛玻璃组件：菜单栏、侧边 Dock、弹窗、悬浮面板 |
| 玻璃填充不透明度 | 浅色：18%；深色：22% | 磨砂底色 |
| 玻璃描边 | 1px 半透明白色（浅色）/ 半透灰（深色） | 所有玻璃面板外边框 |
| 阴影 | 仅悬浮弹窗：垂直偏移 4px，模糊 16px，不透明度 12% | 菜单下拉框、提示弹窗 |
| 窗口圆角 | 20px | 主窗口（无边框窗口） |

### 1.3 交互总则（macOS 人机交互规范）

1. 顶部菜单栏支持窗口拖拽（整栏可拖动窗口）；
2. 所有鼠标 hover 状态要有淡入高亮动画（时长 120ms，ease-out）；
3. 弹窗弹出 / 收起启用透明度 + 缩放动画；
4. 减少动效，避免多层模糊叠加造成帧率下降；同时提供"降低透明度"无障碍开关（写入配置）。

## 二、全局色彩体系（绑定 Doc17 config.ini）

### 2.1 主色调（粉紫主题）

- 主色：`#9D4EDD`（紫粉），hover 态提亮 10%，禁用态降低透明度至 45%
- 辅助色：蓝色 `#3A86FF`（连接成功）、红色 `#F72585`（断开 / 拒绝）、绿色 `#4CC9F0`（在线空闲）

### 2.2 双主题基础色

#### 浅色模式（Light）

1. 窗口底色：`#F7F9FC`
2. 玻璃底色：rgba(255,255,255,0.18) + blur 18px
3. 文字主色：`#1D2129`；次要文字：`#6E7681`；占位文字：`#A0A8B3`
4. 分割线：rgba(0,0,0,0.08)

#### 深色模式（Dark）

1. 窗口底色：`#15171C`
2. 玻璃底色：rgba(255,255,255,0.22) + blur 18px
3. 文字主色：`#F2F3F5`；次要文字：`#909399`
4. 分割线：rgba(255,255,255,0.10)

> 约束：所有色值键名必须同步写入 Doc17 config.ini，QML 代码禁止硬编码色值，统一读取全局 Theme 对象。

## 三、核心组件 UI 规范（重点：菜单栏 + 左侧 Dock）

### 3.1 顶部菜单栏（macOS 现代 BS 菜单栏，核心组件）

#### 布局结构

- 高度：固定 32px；整栏开启 18px 毛玻璃；无边框实色背景；整栏支持鼠标拖拽移动无边框主窗口。
- 布局分为三段：
  1. 左侧：App 图标 + SC 邻桌文字标题
  2. 中间：横向下拉菜单（文件、连接、视图、工具、帮助）
  3. 右侧：最小化 / 最大化 / 关闭窗口按钮 + 主题切换开关

#### 菜单视觉规则

1. 菜单栏本体：BackdropBlur (18px) + 半透底色；无下边框；
2. 菜单项文字：常规字重，字号 13px；hover 时：背景半透高亮（浅色 rgba(0,0,0,0.06)，深色 rgba(255,255,255,0.12)），圆角 6px；
3. 下拉弹出菜单：同样启用 18px 毛玻璃 + 细描边 + 弱阴影；菜单条目高度 28px；hover 高亮；分割线 1px；
4. 菜单弹出动画：透明度从 0→1，缩放 0.97→1，时长 120ms。

#### QML 实现要点

```qml
// 全局毛玻璃封装（固定blurRadius:18）
BackdropBlur {
    radius: 18 // 强制固定值，不可修改
    fill: Rectangle {
        color: Theme.glassBg
        border.color: Theme.glassBorder
        border.width: 1
        radius: 6
    }
}
```

### 3.2 左侧 Dock 侧边栏（macOS 程序坞风格）

1. 位置：窗口左侧固定停靠，宽度 72px；纵向排布图标按钮；
2. 材质：整栏 18px 毛玻璃，与顶部菜单栏材质完全统一；
3. 图标：SVG 矢量图标，尺寸 32px；仅 hover 时出现圆形半透底色高亮；
4. 条目：设备列表、新建连接、文件传输、设置、关于；点击切换主内容区页面；
5. 层级：Dock 悬浮在内容层之上，不遮挡内容核心画面。

### 3.3 主内容区域（严禁玻璃效果）

1. 背景：纯色（读取主题底色），**禁止叠加任何模糊 / 毛玻璃**，保证远程画面、设备列表渲染清晰；
2. 设备列表卡片：圆角 12px，纯色底色，hover 上浮阴影；
3. 远程画面窗口：无边框，画面铺满容器；弹出同意连接弹窗才启用毛玻璃。

### 3.4 弹窗 / 悬浮面板（连接确认、设置窗口、消息提示）

1. 所有弹窗统一材质：18px 毛玻璃 + 1px 细描边 + 弱投影；
2. 连接请求弹窗：居中弹出；按钮分为【同意】（主色）、【拒绝】（灰色）；
3. 设置页面（Doc17 对应页面）：分组卡片布局，卡片为纯色底色，仅标题栏使用毛玻璃；
4. Toast 轻提示：右下角悬浮，小尺寸毛玻璃面板，2 秒自动消失。

## 五、文字排版规范（全局统一字体）

1. 字体：默认系统无衬线字体（Windows：Microsoft YaHei；Linux：Noto Sans；macOS：San Francisco）；QML 统一使用 `font.family: Theme.fontFamily`，不硬编码字体名。
2. 字号层级（全局统一）
   - 窗口标题：16px，Medium 字重
   - 菜单栏文字：13px，常规字重
   - 卡片标题：14px，Medium
   - 正文内容：13px，常规
   - 辅助说明文字：12px，浅灰色
3. 行高：文字行高 = 字号 ×1.3，保证宽松留白，符合 macOS 留白美学。

## 六、动画与动效规范（防卡顿约束）

1. 过渡动画统一缓动函数：`Easing.OutCubic`；时长严格控制：
   - 菜单 hover：120ms
   - 弹窗弹出 / 收起：180ms
   - 页面切换：220ms
2. 硬性限制：**同一时刻，屏幕上最多同时存在 3 个毛玻璃模糊组件**，防止 Qt 渲染性能下降；低性能设备自动降低模糊效果（切换为纯色半透背景，配置项写入 Doc17）。
3. 窗口拖拽无卡顿：菜单栏只做 HitTest，不嵌套多层 Item。

## 七、双主题切换实现规则

1. 全局单例 Theme.qml 管理全部颜色、尺寸、模糊参数；所有组件绑定 Theme 属性，禁止局部写死样式；
2. 切换逻辑：一键切换浅色 / 深色，同步写入 config.ini 持久保存；启动时自动读取上次配置；
3. 毛玻璃自动适配明暗：浅色用白色半透底，深色用深灰半透底，模糊半径始终保持 18px 不变。

## 八、控件统一规范（按钮、输入框、复选框）

### 按钮

- 主按钮：圆角 8px，主色填充，文字白色；hover 轻微提亮；点击收缩 97%；
- 次要按钮：浅色白底灰边框；深色半透玻璃边框；
- 文字按钮：无背景，仅文字变色。

### 输入框（设备别名、IP、密码输入）

- 圆角 8px，1px 边框；聚焦时边框切换为主色；内部留白左右 12px；
- 无人值守密码输入框支持密码显隐切换。

### 列表项（设备条目）

- 高度 44px；左右内边距 16px；hover 背景半透高亮；选中项左侧显示主色竖线标记。

## 九、边界约束与开发红线（必须遵守）

1. 红线 1：**所有毛玻璃组件 blurRadius 必须等于 18px，严禁改成动态亚克力模糊（iOS17 效果）**，严格锁定 iOS16 磨砂质感。
2. 红线 2：内容业务区（远程画面、设备列表、文件列表）禁止使用 BackdropBlur 毛玻璃，仅导航与弹窗可用。
3. 红线 3：所有颜色、尺寸、圆角、模糊参数不允许在 QML 硬编码，全部从全局 Theme 读取，与 Doc17 配置项一一对应。
4. 红线 4：菜单栏必须做成可拖拽无边框窗口标题栏，下拉菜单保持 macOS 原生视觉。
5. 红线 5：所有弹出窗口必须开启弱阴影，玻璃面板必须带上 1px 细半透描边，保证玻璃层次感。

## 十、测试要点（对接 Doc14 测试方案）

1. 视觉一致性：浅色 / 深色双主题下，菜单栏、Dock、弹窗的 18px 磨砂效果正常，无白边、无锯齿；
2. 渲染性能：同时打开菜单栏 + 侧边 Dock + 连接弹窗，帧率稳定 ≥55 帧，无掉帧；
3. 无障碍：开启"降低透明度"开关后，毛玻璃自动降级为纯色半透背景；
4. 交互测试：菜单栏拖拽窗口、菜单项 hover 高亮、下拉菜单弹出动画流畅无卡顿；
5. 多分辨率适配：高 DPI 高分屏自动缩放，圆角、模糊效果不失效。

## 十二、配套开发 Skill 清单（直接落地 QML 代码）

1. Skill1：固定 18px BackdropBlur 毛玻璃封装，区分明暗两套半透底色 + 细描边；
2. Skill2：macOS 现代 BS 横向菜单栏，整栏拖拽无边框窗口，下拉菜单继承同材质玻璃；
3. Skill3：左侧固定 Dock 程序坞，图标悬浮高亮，页面路由切换；
4. Skill4：全局 Theme 单例，一键浅色 / 深色切换，所有样式属性统一绑定；
5. Skill5：弹窗缩放 + 透明度弹出动画，控制动效时长，兼顾流畅度与性能；
6. Skill6：高 DPI 自适应，保证圆角、模糊在高分屏下不失真。

## 十三、双实现对照与扩展说明（本次落地补充）

1. `src/ui/qml`：主实现，ShaderEffectSource + MultiEffect 落地真 18px 背景模糊，`GlobalGlass.qml` 全局复用；
2. `src/ui/qwidget`：对照实现，C++ + QSS。QSS 无背景模糊能力，玻璃面板以半透底色 + 1px 描边 + 圆角模拟磨砂观感（`GlassPanel` 自绘），其余视觉要素（双主题、菜单栏、Dock、弹窗动画）与 QML 版逐项对齐，供比对取舍；
3. QWebEngine 预留：后续若有导入导出 / 报表渲染需求，可在 QML 版引入 `QtWebEngine`（注意：QWebEngine 官方仅支持 MSVC 工具链，MinGW 不可用；届时切换 MSVC 构建目录编译即可，接口层预留 `WebView` 占位组件）。
