# Doc14 测试方案、测试用例、质量准入标准

> 版本：V2.0（2026-10-21 优化：补充无人值守与设置页用例、准入检查表）

## 1. 测试分层

1. 单元测试：gtest，mock ITransport / IDiscovery / ICrypto，测试协议编解码、会话状态机、别名解析、文件分片、鉴权策略，**不依赖网络、不依赖 Qt**
2. 集成测试：两台 Windows 内网机器，真实 UDP + WebSocket 链路
3. 系统黑盒测试：完整业务流程 + 设置页全配置项遍历

## 2. 核心测试用例（等价类 + 边界）

### 2.1 别名设置

合法别名、超长（>20）、过短（<2）、特殊字符、emoji、重名别名、中英数字混合边界。

### 2.2 发现

设备上线、心跳断连自动离线、组播防火墙拦截、静态映射模式、别名冲突告警、256 台上限。

### 2.3 会话流程

发起协助、同意、拒绝、等待超时自动拒、被控主动断开、控制端断开、网络闪断恢复、会话占用时二次请求。

### 2.4 键鼠透传

鼠标移动、左右键、滚轮、键盘中英文输入、快捷键组合、多屏坐标映射（V1.1）。

### 2.5 文件传输

小文件（1 KB）、大文件（4 GB）、文件夹拖拽、中文名、传输中途断开重试、磁盘满、覆盖策略三态、前置确认开关两态。

### 2.6 无人值守模式（Doc16 §9 全集）

- 开关关闭 + unattended 请求 → REJECT(0x03)，不进入挑战
- 开关开启 + 密码正确 → 自动同意 + Toast + 审计日志
- 密码错误 → REJECT(0x01)，失败计数累加
- 挑战超时（>10s 应答）→ 判失败
- 会话中被控点断开 → 立即终止
- 关闭开关 → 新连接走人工弹窗，进行中会话不受影响
- 密码重设后旧密码失效；卸载重装后配置保留行为符合 Doc17 §8

### 2.7 设置页（Doc17 §9 全集）

- 每个配置项：默认值加载、合法修改保存、非法值拒绝并回显
- 需重启项标注正确、热生效项立即生效
- config.ini 手工改成畸形 → 启动兜底默认值
- 员工视图隐藏项不可达、IT 视图全量可见

### 2.8 异常与安全

程序崩溃重启、端口占用、同别名冲突；未同意前不能收到画面、不能发送文件（注入用例）、未鉴权 FILE_CHUNK 丢弃。

## 3. 上线准入标准

| 类别 | 标准 |
| --- | --- |
| 覆盖率 | 单元测试核心模块（protocol / session / auth / filetransfer）≥ 70% |
| 稳定性 | 连续运行 2 h，无内存泄漏、无崩溃（含 30 fps 持续推流场景） |
| 性能 | 内网千兆：画面流畅（≥15 fps）、文件传输 ≥ 40 MB/s |
| 安全 | 所有未鉴权注入用例全部通过 |
| 日志 | 所有高危路径（连接、鉴权、断开、传输失败）日志完整可追溯 |
| 配置 | Doc17 全量配置项遍历无异常 |

## 4. 实测记录（P4~P5 交付回写，2026-10-26）

### 4.1 单元测试（doctest，tests/）

- 覆盖：protocol（含剪贴板帧/KEY_SYNC 帧）/ bounded_queue / config / trust_store / id_service / file_service（name_safe）/ crypto（SHA256/HMAC/PBKDF2 标准向量、GCM 往返防篡改、ECDH 一致性、会话密钥派生确定性）
- 结果：**47 case / 219 断言全绿**（`build-msvc\tests\sc_localdesk_tests.exe`）
- 说明：Doc14 §1 原定 gtest → 实际落地 doctest（header-only，零依赖），断言口径不变

### 4.2 崩溃捕获（MiniDump）

- `SCLD_CRASH_TEST=1` 注入 0xC0000005 → exe 旁 dumps/ 生成 .dmp + .txt（异常码/地址），验证通过

### 4.3 断网重连（PRD P8）

- 钩子：`SCLD_SMOKE_RECONNECT=<N>`，Running 后 2s 主动断开 → 1s 重连循环
- 实测：**100/100 轮全部成功**，双端 会话建立=100/关闭=100 对账一致，异常=0
- 资源：控制端 WS 119MB/句柄 777，被控端 60MB/句柄 507，无泄漏迹象

### 4.4 长稳压测（soak_8h.ps1）

- 首轮 8h 压测于 2026-10-26 00:25 被开发期 E2E 进程清理（taskkill）中止，脚本保护性退出，有效样本 65 行（约 25 分钟）
- 有效样本摘要：WS 133.6→51.4MB（推流缓冲建立后回落）、句柄 805→821 平稳，无泄漏迹象
- **遗留：需 8h 空闲窗口重跑完整轮**（重跑时不得并行执行任何 E2E 冒烟）

### 4.5 剪贴板同步（PRD P9）

- 协议往返/截断/超限拒绝：单测覆盖
- E2E：SCLD_SMOKE_CLIP 钩子单帧同步验证通过；回环防护实测（Windows 剪贴板通知异步且系统全局，QSignalBlocker 无效，最终三重内容去重收敛）

### 4.6 会话加密（PRD 密钥协商，Doc05 §1.1）

- 后端：Windows CNG（OS 内建 bcrypt.lib 零依赖）/ OpenSSL 头探测，缺失降级桩
- 单测：SHA256/HMAC RFC4231 向量、PBKDF2 100001 迭代 Python hashlib 基准、
  GCM 往返+密文篡改拒绝、ECDH 双端共享秘密一致、派生确定性
- E2E（2026-10-26 双实例）：双端日志 `会话加密已启用 ECDH-P256/AES-256-GCM encrypted=yes`
  （协商 <15ms）；加密视频流控制端解码 fps≈15.1 drop=0 全程零"解密失败"；
  会话正常关闭，密钥随 reset_to_idle 清除
